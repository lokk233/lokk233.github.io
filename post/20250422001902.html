1.1.3 PN结

  • P型与N型放在一起，形成PN结

  • 一、

      1. 扩散运动（如图（a））

      2. 空间电荷区：耗尽层，阻挡层，PN结

      3. 漂移运动：P/N区的少子在空间电荷区形成电场的作用下被拉去对面

         在一定条件下，多子的扩散运动与少子的漂移运动就会达到动态平衡

      4. 对称结：空间电荷区两方宽度一样，即P、N两区掺杂浓度一样

        不对称结：浓度高的一方，窄；浓度低的一方，宽。

      5. 势垒：人为抽象的，PN结形成的电场对于多子而言是阻碍的，因此称势垒。

  • 二、PN结的单向导电性

      1. 外加正向电压

        外向电压↑ 势垒↓ ；正向电压增大到一定程度才会有电流，这一程度之前的称为死区

        R为限流电阻，限定通过的最大电流

      2. 外加反向电压

        反向电压↑ 势垒↑ ；几乎不导电，所以从N到P时，是截止的；加强漂移运动； \(I_s\)（反向饱和电流）对温度十分敏感

  • 三、PN结的电流方程

    • \(i=I_s(e^{U/U_t} -1)\) \(U\) 为PN结上所加电压；室温下，\(U_t\) = 26 mV

      导通电压：Ge管：0.2V - 0.3V

                Si管：0.6V - 0.7V

    • PN结伏安特性与下文二极管伏安特性几乎一致

1.3 双极晶体管（晶体三极管）BJT

1.3.1 结构及类型

  • 一、构成方式
  • 二、结构
    • 三个区域、三个电极、两个PN结（发射结、集电结）
    • 发射区e(emitter)：发射载流子的区域，因此掺杂浓度是所有区域当中最高的
    • 集电区c(collector)：收集载流子的区域，相当于仓库，因此掺杂浓度不能过高，但集电区面积得大
    • 基区b(base)：控制区
    • 符号：见图(c)，箭头指向是P指向N，因此可通过箭头指向判断三极管是 NPN型 还是 PNP型

1.3.2 电流放大作用

  • 一、放大

    • 向三极管b输入电流\(I_b\) , 一定条件下c和e通过电流\(I_c\) ，\(I_c/I_b\) 近似于一个常数(称为 β)，也就是说 \(I_c\) 是 \(I_b\) 的放大。

      （本质上就是小电流变化控制大电流变化罢大概）

      当然，能量守恒，所以\(I_c\)是通过三极管c极连接的电源而来，所以三极管实际上更像是一个控制元件，用于控制外部电源的功率。

      放大最基本要求：不能失真

  • 二、基本共射放大电路

    • 图中，\(R_b\)作用：限流电阻，防止发射结两端电压过大导致正向导通击穿三极管。

      \(V_{CC}\) ：处于三极管ec之间，比 \(V_{BB}\) 大，说明发射结在这时是正向导通的，称这种情况为正向偏置

    ​

    • 正向偏置（正偏） PN结导通

    • 反向偏置（反偏） PN结截止

    • 此图中，发射结正偏，集电结反偏 （因为N的电压比P的电压大，截止了）

      \(I_c\)与\(I_b\)成比例

  • 三、晶体管内部载流子的运动

    • 1.发射结正偏

      发射区的自由电子 扩散 至 基区 形成电流\(I_{EN}\)

      基区的空穴 扩散 至 发射区 形成电流\(I_{EP}\)

      因为正偏即向PN结外加正向电压，导致势垒降低，扩散运动加强，而发射区浓度高，所以发射区自由电子扩散至基区

      \(I_{EN}\) >> \(I_{EP}\) ，\(I_{EN}\) + \(I_{EP}\) ≈ \(I_{EN}\)

    • 2.基区(实现放大的关键)

      发射区自由电子扩散至基区后，基区非平衡少子（自由电子）过多并向集电结漂移。形成电流\(I_c\)

      当然，发射区自由电子到基区必然会与基区空穴复合，要保证发射区自由电子能够到达集电区，基区需要非常薄且掺杂浓度低

      少部分自由电子与空穴复合，基区通过基极从\(V_{BB}\) 补充空穴，因此形成\(I_b\)

      整个过程一直持续，\(I_c\) 与 \(I_b\) 逐渐成比例

    • 3.集电区

      要使发射区自由电子可以更加顺利地到达集电极，需要集电区反偏，这样即可通过漂移运动收集自由电子，从而达到效果。

      至此，整个正常工作的三极管就相当于一个导体。

    • 4.放大系数

      • 1.直流电流共射放大系数：\(\overline{β} = I_{CN}/I_{BN} = (I_C-I_{CBO})/(I_B+I_{CBO})≈I_C/I_B\)

        (\(I_{CN}\) \(I_{BN}\) 通过kcl得到)

        交流电流共射放大系数：\(β=\triangle I_C/\triangle I_B\)

        通常情况下 \(\overline{β}\) 与 \(β\) 数值接近

      • 2.穿透电流 \(I_{CEO}\) : \(I_B\)为0时，理论上三极管不导通，但实际上还是有微小的电流穿过，即穿透电流\(I_{CEO}\)

      • 3.反向电流 \(I_{CBO}\)：集电结加反向电压时平衡少子的漂移运动形成的

      • 4.直流电流共基放大系数：$ ≈ I_C/I_E = /(1+) $

1.3.3 BJT共射特性曲线

  • 一、输入特性

    • 即 \(i_B\) 与 \(u_{BE}\) 之间的关系。

    • 考虑到正常工作的三极管还有\(u_{CE}\) ，所以要研究 \(i_B\) 与 \(u_{BE}\) 之间的关系，需将\(U_{CE}\) = 常数

    • $i_B = f(u_{BE})|{U{CE} = 常数} $

    • 由图可见，\(U_{CE}\)越大，曲线向右移动，但\(U_{CE}\)>=1V时，曲线基本不会再向右移动了，即\(U_{CE}\)>=1V的曲线基本重合。

      （因为集电结反偏，\(U_{CE}\)增大漂移运动增大，\(i_B\)电流减小，要获得同样的\(i_B\)电流，\(u_{BE}\)要增大，\(U_{CE}\)大于1V后，漂移运动动态稳定，\(u_{BE}\)不变）

    • 曲线簇

  • 二、输出特性

    • 即 \(i_B\) 与 \(u_{BE}\) 之间的关系。

    • $i_C = f(u_{CE})|_{i_B = 常数} $

    • 集电结正偏，晶体管处于饱和状态，集电结反偏，晶体管处于放大状态

    • \(U_{CE}\) > 曲线拐点处，说明集电结已经反偏了，此情况下，只要\(i_B\)不变，\(i_C\)就是一个固定值

    • 放大状态下\(i_C\)与\(i_B\)成比例

    • 曲线簇

    • \(i_B\) = 0时，仍有微小的电流，此电流即为\(I_{CEO}\) （穿透电流），\(I_{CEO}\) 越小，截止越接近理想

    • 饱和区中，\(i_C\)与\(i_B\)不成比例，说明\(i_C\)不受\(i_B\)控制；\(U_{CE}\)非常小，导致集电结正偏 ；集电结与发射结都为正偏，此时\(U_{CE}\)很小(基本上为管压降，称之为饱和电压\(U_{CES}\))；

      从外电路看，\(i_C\)随\(i_B\)增大，随后停留在一个固定值，（因为正偏的时候，上下二极管都正偏，压降抵消，从外电路看就UCE等于0，此时你Ib无论怎么增大，VCE都为0，即饱和）

      \(i_C = (V_{CC}-U_{CE})/R_C\)

    • 1.放大区：\(i_C = βi_B\)

    • 2.截止区：双结反偏（主要是发射结反偏），ce断路，相当于开关打开，即基极电位小于发射极电位，即可控制晶体管处于截止区

    • 3.饱和区：双结正偏 ，饱和电压\(U_{CES}\)(即\(U_{CE}\) 的最小值)，ce两个电极之间相当于开关闭合（导线），此时\(\overline{β}i_B > i_{CMAX}\)

      (\(i_{CMAX} = (V_{CC}-U_{CES})/R_C\))

      所以若要判断晶体管工作状态，可以算出\(i_B\) (*$i_B =(V_{BB}-U_{BE})/R_B \(* ) 然后比较\)i_B$ 与 \(i_{CMAX}\) 之间的大小，大于即为饱和区，小于即为放大区，发射结反偏即为截止区。

      由输出特性可知，可通过控制\(i_B\)大小使晶体管可以在饱和区与截止区之间来回跳变，起到电子开关的作用，于是可用晶体管控制电路

      三极管最也多用于放大

1.4.2 绝缘栅型场效应管 （MOSFET（MOS））

  • 一、N沟道增强型MOS管

    • 1.结构

    • g栅极，s源极，d漏极（分别对应晶体管b, e, c）

    • 由于g被二氧化硅包围所以绝缘

    • 2.工作原理

    • 对应晶体管c与e之间产生电流，MOS管d与s之间也应产生电流，然而由图可知，s与d之间存在两个PN结以及P（衬底），导致s的自由电子难以到达d，需要在s与d之间形成一个供自由电子通过的沟道

      • 1.\(u_{DS} = 0\) , \(u_{GS}>0\)

        由图（a）可知，\(u_{GS}\)刚上升时，形成由g到B的电场，将上方的空穴推至B，形成几乎没有载流子的PN结（耗尽层），

        继续增大\(u_{GS}\)，不仅将空穴推至B，还将P中的少子（自由电子）吸引至g，情况变为图（b）所示，构成反型层（即沟道），使得N与N之间导通了。此沟道中，多子为自由电子，因此得名N沟道。

        \(u_{GS}\)越高，沟道越宽；\(u_{GS}\)越低，沟道越窄；沟道宽窄决定d与s之间的电阻大小，所以此时MOS管相当于可用电压控制的可变电阻器

        即\(u_{GS}\)控制\(R_{DS}\)

        在d与s施加电压，自然形成电流\(i_D\)

      • 2.要形成沟道，需要一定大小的\(u_{GS}\)，因此由开启电压\(u_{GS(th)}\)

        \(u_{GS} > u_{GS(th)}\) 并保持不变，\(u_{DS}\)不等于0且持续上升

        • 图（a）：\(u_{GS}\)不变，\(u_{DS}\)持续上升，沟道d侧变窄，而沟道s侧宽度不变，说明\(u_{GS}\)实际是沟道s侧上下两点的电压差;

        而沟道d侧上下两点电压差为\(u_{GS} - u_{DS}\)

        在沟道尚未封闭前（即图（a）），阻值基本不变，\(i_D\)随\(u_{DS}\)增大而上升

        • 图（b）：\(u_{GS} - u_{DS} = u_{GS(th)}\)，出现预夹断

          并非真正夹断，一旦断了，沟道没电流没压降，\(u_{GS}\)再次将其打开一个很小的缝隙，可见这是一个自动的平衡状态

        • 图（c）：\(u_{DS}\)继续上升，空隙越长，电阻\(R_{DS}\)越大，导致\(i_{DS}\)几乎不变，相当于恒流（增加的电压都用于抵抗电阻）

          说明恒流区中，\(i_D\)只受\(u_{GS}\)影响

          说明恒流区中，栅极与源极之间的电压\(u_{GS}\)可以控制\(i_D\)，即\(i_D\)与\(u_{GS}\)成比例，处于恒流区的MOS管可用于放大

          预夹断前，相当于可变电阻

          预夹断后，进入恒流区，相当于放大

    • 符号：通过箭头方向判断其为N沟道还是P沟道，（与之前一样，箭头由P指向N）

    • “增强”含义：说明d、s天生不可通（无沟道）需要增强\(u_{GS}\)电压

    • 要使MOS管d、s天生导通（有沟道），可见下方另一种MOS管

  • 二、N沟道耗尽型MOS管

    • 在g的下方增加了正极板

    • \(U_{GS(off)}\)夹断电压，只要\(U_GS\) >\(U_{GS(off)}\)，MOS管正常工作（导通）

    • 符号见图上（b）

1.4.1 结型场效应管

  • 一、结构

    • 一大块N上下掺杂高浓度的P

    • 换个视角↓

    • 图中两个P区连接在一起，连接g极（栅极），栅极控制着两个P，P与N之间形成PN结，

      若栅极源极（gs）之间0电压，此时结型场效应管相当于N沟道耗尽型MOS管，d与s之间天生存在沟道

      要控制该管，需在g和s之间加负值的电压\(u_{GS}\)，使PN结反偏，PN结变宽

    • \(u_{GS}\)加到底导致沟道夹断（真夹断，如图（c）所示），此时不导电（截止）

    • 如何工作？

    • \(u_{DS}\)越大，上方（d侧）PN结越厚，最后出现预夹断；与MOSFET类似，在预夹断前，存在固定的电阻

    • 预夹断前，\(u_{GS}\)不变，电阻不变。当\(u_{GS}\)固定，\(u_{DS}\)与\(i_D\)之间成正比

    • 预夹断后，\(i_D\)不变，恒流，此时\(i_D\)只和\(u_{GS}\)有关

    • \(u_{GS} > 0\)会导致PN结正偏，发生PN结导通，导致短路

    • 与MOS管区别：

      • 1.结型场效应管PN结仍有微小的反偏的漏电流，但MOS管是绝缘栅，基本无电流，即输入电阻没有MOS的高
      • 2.结型场效应管不能工作在\(u_{GS} > 0\)的状态下
      • 优点：不容易损坏，而MOS管电容小（\(Q/C = U\)），只要存在一点电荷就有可能产生电压，形成足以击穿MOS管的电场。

1.4.3 场效应管的特性曲线与参数

  • 一、特性曲线

    • 1.转移特性曲线(图a)（输入特性曲线）

    • 转移特性说明: \(u_{GS}\)控制\(i_D\)

    • 图（a）曲线出现条件：MOS一定工作在恒流区，即\(u_{DS}\)需足够大（不在恒流区的话，\(i_D\)受到\(u_{GS}\)和\(u_{DS}\)影响）

    • 电流方程：\(i_D = I_{DO}(u_{GS}/u_{GS(th)} - 1)^2\)
