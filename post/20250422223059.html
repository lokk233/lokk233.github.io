第二章 基本放大电路

2-1 放大电路的构成

2.1.1 放大的概念

  • 一、特征

    • 功率放大

      放大指的是将功率放大，输入小功率信号经过放大电路输出大功率信号，由P=UI可知，可通过放大电压或放大电流等方式达到放大功率的效果

  • 二、本质

    • 能量的控制以及转换（大功率信号的能量来源于放大电路中外接电源）

  • 三、必要条件（核心器件）

    • 有源元件（即能量控制元件，如三极管、场效应管等）

      该器件的能量由外部电源提供

      通过小信号的输入控制输出的一个大信号，实现输出与输入成比例，可控。

  • 四、前提

    • 不失真（保真）

  • 五、测试信号

    • 正弦波 （因为各种复杂信号都可视为各种频率的正弦波的叠加）
    • 如何确定保真——通过一系列测试信号测试

2.1.2 怎样构建基本放大电路

  • 一、目标：小功率信号 -> 大功率信号

  • 二、条件：1.元件（有源元件）2.能量（电源）

  • 三、技术路线：

    • 1.使三极管工作在放大状态下，此时\(i_B\)可以控制\(i_C\)

    • 2.使小信号控制\(i_B\)(\(u_{BE}\)​)

      • 通常会加直流电源将小信号电压推至可以开启三极管的电压（发射结正偏）
      • 加限流电阻\(R_B\)保护电路和三极管
      • 实际上就是\(i_B\)​控制ec间电源输出多大功率的电流

    • 3.合理的输出

      如何输出？

      • 如下图，连接负载\(R_L\)，可以看到，负载电压为\(E_C\)，流过负载的电流仍是一个直流电流。
      • 要想让交流电流\(i_C\)流过负载：
      • 1.可使负载直接连接至三极管d极所在支路；
      • 2.将交流电流变成电压信号输出
      • 使交流电流流经一个电阻，即可取出信号，见下图
      • 如图添加\(R_C\)后，\(R_C\)的压降即为电压信号，此时负载\(R_L\)的电压即为\(E_C - i_CR_C\)​
      • 基本共射放大电路便是这样而来↓
      • (学习或分析电路时，可以试着一步步构建相同的电路，以此了解各个器件在此电路的用处)
      • 无直流电源，无法启动三极管，无\(i_B\)产生，那么基本共射放大电路是无法使用的↓

  • 四、放大电路

    • 1.直接耦合

      • 由该图可以看到，电源，此电路一口气用了两个！实际臃肿！

        因此，有无办法只用一个电源？——可

        只要保证集电结反偏（即b极电位小于c极电位）即可

        但是，如果直接将交流信号加至\(R_B\)所在支路，会出现交流信号因没接地而出现受干扰的情况

        所以↓

        但是，这样的电路，\(u_{BE}\)实际\(u_i\)，不足以使发射结正偏，\(i_B\)不会流入三极管反而会直驱左路进入小信号。

        所以↓

        添加一个电阻，此时由叠加定理可知b极的电位变为交直流叠加的电位

        化简一下电路，直接耦合共射放大电路由此而来↓

        耦合：信号在电路之间传递的过程称为“耦合”

        直接耦合：输入信号与输出信号在放大电路的传递不经过任何东西直接连接

        此电路的\(u_i\)效率不高，因为\(R_{b1}\)与\(R_{b2}\)分压后才给到b极

        另外输出至\(R_L\)​的电压实际上带着直流的，并非纯交流

        要想达到输入纯交流输出纯交流的效果，可以设计如下电路↓

    • 2.阻容耦合

      • 电容用于隔断直流连通交流，电容\(C_1\)隔断直流电流\(i_B\)，使其只能通过三极管发射结；用戴维南定理等效前端电路并分析可以看出，电容\(C_2\)可将\(u_o\)中的直流滤除。↓

  • 五、工作原理

    • 1.无输入信号:

      • 此图相当于喇叭开机但不说话（无信号输入，工作在放大状态下）

      • 无输入信号时，\(C_1\)、\(C_2\)相当于断路，存在\(u_{BE}\)使三极管工作在放大状态下，由输入特性曲线可知存在\(i_B\)，每一个\(i_B\)都有一个输出特性曲线与之对应。

        输出特性曲线为\(i_C\)与\(u_{CE}\)的关系，当三极管工作在放大区时，\(i_C\)与\(i_B\)成比例，\(i_C\)有着与之对应的\(u_{CE}\)。这说明放大状态下三极管T的ce之间存在电压\(u_{CE}\)且\(u_{CE}\)在自动调节变化，并以此保证\(i_C\)与\(i_B\)成比例。

        \(ic = (U_{CC} - u_{CE})/R_C\)，\(i_C\)随着\(u_{CE}\)变化，所以\(u_{CE}\)是一个可变化值，是根据外电路而来的，无输入信号时，\(u_{CE} = U_{CC} - (i_CR_C)\) 。

    • 2.有输入信号：

      • 加入信号\(u_i\) ，\(u_i\)变化引起\(u_{BE}\)，\(u_{BE}\)引起\(i_B\)变化（输入特性曲线），\(i_B\)变化引起\(i_C\)变化，\(i_C\)变化引起\(u_{CE}\)变化，最后输出\(u_o\)。（\(u_o\)反相）
      • 直流加交流使得总电流在变化的时候仍然是正的。

2-2 性能指标

  • 一、示意图（由戴维南定理而来）

  • 通过戴维南定理将输入信号等效成电压源（或电流源）与电阻\(R_S\)串联，将放大电路等效成输入电阻\(R_i\)(对于输入信号而言)；对于\(R_L\)来讲，放大电路以及输入端可等效成电源与内阻相串联的形式，\(R_o\)即为输出电阻

    • 输入：

      • 若信号源为电压源，\(R_i\)越大越好：

        1. \(\dot {U_i} = [R_i/(R_i + R_S)]*\dot {U_S}\)，\(\dot {U_i}\)越大越好。所以当信号源为电压源时，输入电阻\(Ri\)越大越好。

        1. 戴维南定理等效而来的\(\dot U_S\)​是理想电压源（功率无穷大），而现实电压源若输出过大功率会导致失真，所以需要减小信号源的功率输出

          要减小信号源的功率输出，需要\(\dot I_i\)减小，所以\(Ri\)​越大越好

    • 输出：

      • 如果希望输出一个稳定电压（即希望前端的放大电路近似一个电压源），即要求\(R_L\)上的\(\dot U_o\)稳定，那么根据分压公式求输出\(\dot U_o\)，也就是\(R_C\)和\(R_L\)两个电阻分压，此时\(R_C\)越小，\(R_L\)分得越大，也就越稳定了。（因为相当于Uo全都加在RL上了，RL变化，但是两端的电压近似不变，类似电压源）
      • 如果参数要求\(R_L\)变化时\(\dot I_o\)几乎不变，则要求前面近似为一个电流源，此时\(R_o\)越大（由诺顿定理可得），\(R_L\)分得的电流越小，那么\(\dot I_o\)受\(R_L\)变化的影响越小。

  • 二、放大倍数

    • \(A_{UU}\)：\(U_o / U_i\)
    • \(A_{UI}\)
    • \(A_{IU}\)
    • \(A_{II}\)

  • 三、输入电阻\(R_i\)

  • 四、 输出电阻\(R_o\)

对于多级放大电路，前一级的负载\(R_L\)为下一级的输入电阻，第二级的输入电阻即为前一级的负载。

前一级的放大电路相当于下一级的信号源。

所以遇到多级放大电路，\(R_i\)、\(R_o\) 以及 等效思路 很重要

  • 五、通频带

    • 对于阻容耦合放大电路，
    • 信号源频率越低，电容容抗越大，信号越难进入放大电路​​，使得输出信号衰减。
    • 信号源频率越高，当频率不断升高，结电容容抗不断减小，使得电流旁路（指电流从结电容流过）导致电流放大倍数越来越小，输出的信号也会越来越小（衰减）
    • 低频和高频都会导致放大倍数衰减，中间不会使信号衰减的频带称为通频带

  • 六、非线性失真

  • 七、最大不失真输出电压

  • 八、最大输出功率与效率：在不失真前提下，最大输出功率与输入功率之比即为效率（功放效率）

    以后的各类学习中都会关注以上各类参数。

2-3 分析方法

  • 如何分析，首先回顾二极管的分析过程，对于二极管电路，交流的\(u_D\)产生交流的\(i_D\)，可以看出二者的关系与静态工作点Q所在位置是有联系的。

  • 对于三极管，由晶体管输入特性曲线可知，变化的\(u_{BE}\)与变化的\(i_B\)之间的关系必然受直流点（静态工作点Q）的位置有关

  • 所以同样的\(u_{BE}\)变化会因Q点位置不一样而导致出现不同的\(i_B\)变化，\(R_C\)上的压降也会跟着变大，从而直接影响\(u_{CE}\)，使得\(u_o\)变大

  • 所以，若要分析动态，必须先分析要在哪个点上进行动态，即先分析静态工作点。

2.3.2 图解法

  • 在电路分析基础中，用图解法分析非线性电路，此处分析放大电路同理

  • 首先，在输入特性曲线上找出Q点（根据\(i_B = (V_{BB} - u_{BE})/R_b\)得到Y轴截点与X轴截点的连线，连线与曲线交点即为Q点），随后引入\(\Delta u_i\)并画出连线与曲线交点，得到\(\Delta u_{BE}\)，进而得到\(\Delta i_B\)。

    随后，在输出特性曲线上根据Q点找到\(I_B = I_{BQ}\)曲线，再根据\(\Delta i_B\)找到$I_B = I_{BQ} + i_B \(曲线，由\)i_C = (V_{CC} - u_{CE}) / R_C\(得到连线与曲线\)I_B = I_{BQ} + i_B \(的对应交点，由此可得到\)u_{CE}\(进而得到\)i_C\(和\)u_{o}$

    即可得到各放大系数，如\(\Delta u_{o} / \Delta u_i\)等

    加入正负\(\Delta u_i\)同理即可得到\(\Delta i_B\)波形

  • 三极管为非线性元件，想用图解法以外的方法分析，需要将其等效为线性电路

2.3.3 等效电路

  • 阻容耦合放大电路中，

    纯交流(低频小信号)作用时，\(u_i\)产生\(i_B\)，\(i_B\)输入，\(i_C\)输出

    \(i_C=βi_B\)

    \(u_o = u_{CE} = -i_CR_C\)

    以上两式可以看出\(i_C\)与\(i_B\)存在线性关系，\(u_{CE}\)、\(u_o\)与\(i_C\)亦是

    但，关键是，\(i_B\)与\(u_i\)之间的关系，或者说，\(i_B\)与\(u_{BE}\)之间的关系（输入特性曲线）不是线性的（见上图(a)）

    显然 \(i_B\) 与 \(u_{BE}\) 的关系非线性，但通过微分的方法处理可知，当 \(\Delta u_{BE}\) 足够小，可将 \(\Delta u_{BE}\) 所对应曲线近似为一段直线段，此时可将 \(\Delta u_{BE}\) 与 \(\Delta i_B\) 的关系视作线性关系

    所以，可定义一个动态的电阻 \(r_{be} = \Delta u_{BE} / \Delta i_B\) ，即直线的斜率倒数

    那么，\(r_{be}\) 可用与等效发射结两端的端口。

    注：以上过程的前提是在只考虑交流变化量的影响下进行，无需再次考虑直流源带来的影响，因为直流电源的作用已经隐含在Q点了

    对输入而言，三极管等效成输入电阻 \(r_{be}\)

    对输出而言，三极管等效成受控电源\(βi_B\)

  • 一、直流通路

      1. 作直流通路
        1. 找出静态工作点Q

  • 二、交流通路

      1. 作交流通路
        1. 将三极管等效成如右图所示

  • 大致分析流程

      1. 作直流通路，已知开启电压\(U_{BEQ}\)，那么 \(I_{BQ} = (V_{CC} - U_{BEQ}) / R_b\) , \(I_C = βI_{BQ}\) ， \(I_{EQ} = (1+β)I_{BQ}\) ( 因为 \(I_{EQ} = I_{BQ} + βI_{BQ} = (1+β)I_{BQ}\) )，最后求得\(r_{be}\)

        判断三极管处于饱和还是放大， 先求\(I_{Cmax} = (V_{CC} - U_{CES}) / R_C\)， 若 \(I_{Cmax} < βI_B\) : 饱和 （\(I_C = I_{Cmax}\) \(u_{CE}\)非常小）

        1. 做交流通路

        2. 从交流通路变为微变等效电路

          \(i_B\)：含直流交流

          \(I_b\)：\(i_b\)的有效值

          \(\dot I_b\)：\(i_b\)的相量

        3. 求放大倍数，如\(A_u = u_o/u_i\) 等

        4. 通过戴维南定理求得输入电阻\(R_i\)、输出电阻\(R_o\)​

  • (下面是从数学角度推出等效电路)

  • 相同的输入信号、相同的三极管，输出会因静态工作点的不同而不同

  • 图(a) ,由晶体管输入特性曲线可知，\(i_B\) 不仅受 \(u_{BE}\) 影响，还受到\(u_{CE}\)​影响

  • 所以 \(u_{BE}\) 与 \(i_B\) 的函数关系

  • $\[\begin{equation}\begin{cases}u_{BE} = f(i_B , u_{CE})①\\i_C = f(i_B,u_{CE})②\\ \end{cases}\end{equation}\] $

    （①为输入端口函数关系，②为输出端口函数关系）

    已知以上的函数关系，要求得以上变量在微分下的关系，可根据上式作全微分↓

    $ d{u}{BE}, =, {{B} }{|}{ {U}{CE} }d{i}{B}+ {{CE} } {|}{ {I}{B} }d{u}_{CE} $ （其中\({U}_{CE}\)、\({I}_{B}\)为直流变量，(常数)）

    $ d{i}{C}, =, {{B} }{|}{ {U}{CE}}d{i}{B}+ {{CE} }{|}{ {I}{B}}d{u}_{CE} $

    用参数\(h\)取代化简上式得：

    $ d{u}{BE}, =, {h}{11}d{i}{B}, +{h}{12}d{u}_{CE} $ ①

    $ d{i}{C}, =, {h}{21}d{i}{B}, +{h}{22}d{u}_{CE} $​ ②

  • 由此可通过上面的方程构架等效电路：

    输入端有\(di_B\) 和 \(du_{BE}\) ，输出端有\(di_C\) 和 \(du_{CE}\)

    ①式中电压\(du_{BE}\)​​ 等于 两变量 相加 ，（电压串联为相加，电流串联为相加），表现在等效电路中即阻抗与受控电压源串联；②式同理，可将 在只有低频小信号作用的放大电路 等效为 h参数等效模型(下图↓)

  • 由上面①②式可知：

    \(h_{11} = \frac {\partial {u}_{BE}} {\partial {i}_{B}}{|}_{ {U}_{CE}} = r_{be}\)

    \(h_{12} = \frac {\partial {u}_{BE}} {\partial {u}_{CE}}{|}_{ {I}_{B}}\) ，由上图(a)可知，当 \(u_{CE}\) > 1 V 时，\(u_{CE}\) 变化 给 \(u_{BE}\) 带来的 变化 几乎没有，即\(h_{12}\)​非常小（0.01的程度），几乎可以忽略，如此即可忽略受控电压源

    \(h_{21} = \frac {\partial {i}_{C}} {\partial {i}_{B}}{|}_{ {U}_{CE}} = β\)

    \(h_{22} = \frac {\partial {i}_{C}} {\partial {u}_{CE}}{|}_{ {I}_{B}}\) ，由上图(b)可知，\(i_{C}\) 变化 给 \(u_{CE}\) 带来的 变化 几乎没有，即\(h_{22}\)​ ， 几乎可以忽略，如此即可忽略阻抗

    至此，h参数等效模型可化简为↓

  • 在求得静态工作点后，如何求解\(r_{be}\)?

    \(r_{bb'}\)是基区里的体电阻（一般可在元件的数据手册中得知）; \(r_{e'}\)是发射区的体电阻，但因发射区掺杂浓度过高电阻过小所以可忽略不计。

    \(r_{b'e'}\) 实际上是发射结电阻，关于发射结电阻求解方法在上一章有记录，(\(r_d = \frac {U_T} {I_d}\))

    注意，流过发射结的电流\(I_d\)即为\(\dot I_e\)，因此\(r_{b'e'}\)实际与\(i_{eq}\)​相关

    从上图(b)可得到下列等式

    $u_{be} = I_b r_{bb'} +I_e r_{b'e'} $ (式中\(\dot I_e = (1+β)\dot I_b\))

    $r_{be} = r_{bb'} + (1+β)r_{b'e'} $ (式中\(r_{b'e'} = \frac {U_t} {I_{EQ}}\))

    既然\(I_{EQ} = (1+β)I_{BQ}\) 那为何不直接 \(r_{be} = r_{bb'} + \frac {U_t} {I_{BQ}}\) ？

    因为\(r_{be} = r_{bb'} + \frac {U_t} {I_{BQ}}\) 没有物理意义。
